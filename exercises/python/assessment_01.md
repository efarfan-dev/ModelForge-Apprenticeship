# Exercise 01: Count Occurrences

Implement count_occurrences(items) in assessment_01.py
without an AI-generated solution.

Input:
["apple", "banana", "apple"]

Expected output:
{"apple": 2, "banana": 1}

Requirements:
- Empty lists return an empty dictionary.
- "Cat" and "cat" count separately.
- Do not change the original input.

Stretch:
Implement most_common(items), using alphabetical
order to break ties and None for empty input.

Run:
python -m unittest discover -s tests -v
